# Synaptech Design Solutions

A static portfolio site for Synaptech Design Solutions, featuring categorized project pages and interactive project previews.

## Local preview

```powershell
npm start
```

Open `http://localhost:5000`.

## Homepage concepts

- `http://localhost:5000/home-concept-1.html` — Open Field + interactive project map

Each concept is a single-screen, brand-led direction with links to switch between all three.

The design research behind the selected homepage is summarized in `competitor-profiles/_summary.md`.
